Where should the Report Builder UI live?

Where does the user go to configure P&L and Balance Sheet account mappings?

A

Inside Reports Page — "Configure" button

On the P&L / Balance Sheet panel, a ⚙ Configure button opens a side-drawer or inline panel to map accounts. User stays in the reports flow.

Reports › Profit & Loss
Profit & Loss
⚙ Configure ▶ Run Report
[ Configure drawer slides in → map accounts to P&L lines ]

Pros

  • Contextual — configure right where you run the report
  • No separate navigation

Cons

  • Clutters the report page
  • Drawer/modal adds complexity
B

Dedicated Settings Page — "Report Builder"

A new page under Settings (like Chart of Accounts) called "Report Builder". User goes there once to configure, then runs reports normally.

Settings › Report Builder

P&L Line → Account Mapping

Pros

  • Clean separation — configure once, use always
  • More screen space for the mapping UI

Cons

  • User must navigate away from Reports to configure
