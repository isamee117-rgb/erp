Schema::create('report_line_mappings', function (Blueprint $table) {
  $table->string('id'); // 'RLM-xxxxxxxxx'
  $table->string('company_id');
  $table->enum('report_type', ['profit_loss', 'balance_sheet']);
  $table->string('line_key'); // 'sales_revenue', 'cogs', 'operating_expenses', etc.
  $table->string('account_id'); // FK → chart_of_accounts.id
  $table->timestamps();
  $table->primary('id');
  // one account → one line per report (no double-counting)
  $table->unique(['company_id', 'report_type', 'account_id']);
});

One row per account-to-line mapping. The unique constraint ensures an account can't be mapped to two lines in the same report.

New: ReportBuilderController

app/Http/Controllers/Api/ReportBuilderController.php — 2 methods
GET /api/report-builder/{type}

Returns the full line definition (all predefined lines) with the currently saved account mappings per line. Keyed by line_key. Used by the Settings page to populate dropdowns.

PUT /api/report-builder/{type}

Accepts { mappings: { line_key: [account_id, ...] } }. Deletes all existing mappings for that report type + company, then inserts the new ones. Returns the updated config.
